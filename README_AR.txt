صدى العراق — حزمة Railway خفيفة

الإصدار: 6.6

هذه الحزمة مخصصة للنشر على Railway. تتضمن ملفات تشغيل التطبيق وإعداداته الأساسية واختبارات الصيانة، وتحذف النسخ الفارغة من بيانات التشغيل والوثائق التاريخية ومخرجات استضافات غير مستخدمة. لا تتضمن الحزمة بيانات مستخدمين أو أسرار جلسة مولّدة محلياً؛ ينشئ الخادم ملفات التشغيل الافتراضية عند بدء التشغيل.

أهم ما يشمله الإصدار 6.6
- إصلاح تكرار أيقونات الفئات والخدمات مع الحفاظ على أيقونة واحدة داخل عنصر الفئة، دون التأثير على أزرار اختيار المنصة أعلى الصفحة.
- جعل شريط أعلام بطاقة القائمة الجانبية بعرض البطاقة الكامل وبحركة مستمرة، مع إبقاء الحركة خفيفة واحترام إعداد تقليل الحركة. أضيف تمييز أحمر خفيف لبطاقة صدى العراق التي حددها المستخدم فقط.
- الاحتفاظ بصفحة «رابط الدعوة الخاص بك» الطويلة ومحتواها وأزرار النسخ والفتح والمشاركة، مع إزالة إحصائيات طلبات الموقع منها. الإحصائيات المرتبطة بالإحالة تبقى غير متاحة حتى يوفّر الخادم بيانات حقيقية.
- الحفاظ على تحويل الأرقام المعروضة إلى الأرقام الإنجليزية، وتحسين صفحة «من نحن»، وصفحة «طلباتي» وتحميلها، والمتجر والأسعار بالدولار وزر الرجوع.
- الحفاظ على اختبارات الإلغاء والاسترداد الجزئي ومنع تكرار الرصيد واختبار نسبة الربح الوهمية.

النشر على Railway
1) استخدم Node.js 22 أو أحدث.
2) ارفع جميع محتويات ZIP إلى جذر المستودع؛ يجب أن يحتوي الجذر على server.js وpackage.json وrailway.json.
3) اجعل Build Command = npm run build، وStart Command = npm start (كما في railway.json).
4) نفّذ npm test محلياً قبل النشر. يعتمد npm test على مجلد tests المضمّن في هذه الحزمة.
5) لإبقاء الملفات المحلية على Railway، اربط Volume وحدد SADA_DATA_DIR أو دع الخادم يستخدم مسار Railway Volume. لا تضع مفاتيح Firebase أو API في الملفات العامة.

قاعدة البيانات والأمان
- إعدادات Firebase وقواعدها محفوظة في config.json وdatabase.rules.json.
- admin-auth.json ملف خاص بالمشروع؛ لا ترفع المستودع إلى مكان عام ولا تشارك الملف مع الآخرين.
- استُبعدت مجلدات البيانات المحلية الفارغة وملف سر الجلسة المتولد من هذه الحزمة، ويعيد الخادم إنشاء ملفات التشغيل الافتراضية. لم نصل إلى قاعدة Firebase الحية ولم نعدّل بيانات الإنتاج.
- نجاح الاختبارات المحلية لا يثبت وحده الاتصال الحي بـFirebase أو مزود الخدمات بعد النشر.

فحوصات الإصدار
- npm run build: فحص بناء/تطابق ملفات الإصدار.
- npm test: اختبارات الاسترداد الوهمي، والعدّ الفعلي الموحّد للطلبات، وواجهة الإصدار والأيقونات والأعلام ورابط الدعوة.
- لم يتم نشر هذه الحزمة تلقائياً إلى حساب Railway؛ اختبر الموقع الحي بعد النشر.
