صدى العراق — حزمة تشغيل خفيفة

الإصدار: 5.6

الملفات في هذه الحزمة مقتصرة على ملفات التشغيل والإعدادات الأساسية وملفات النشر.
تم حذف ملفات الاختبارات المنفصلة والتقارير التاريخية من نسخة النشر لتقليل حجم وعدد الملفات؛ هذا لا يحذف وظائف الموقع من server.js أو الواجهتين.


الإصدار 5.6 — تجميع إصلاحات الواجهة والطلبات
- منع تكرار أيقونات المنصات في عناصر الفئات والخدمات وتوحيد أعداد الفئات بالأرقام الإنجليزية.
- إضافة مهلة تحميل وإعادة محاولة لطلبات المستخدم، مع إبقاء النتائج السابقة عند تعذر التحديث الصامت.
- توحيد خلفية صفحة إنشاء الطلب بالفحمي والذهبي الدافئ، وتنظيم تنقل الإدارة وتقرير مزامنة الخدمات والأسعار.
- يلزم التحقق الحي بعد النشر من Railway والمزود وFirebase؛ الاختبارات المحلية لا تثبت الاتصال الفعلي.

تشغيل Railway أو Render
1) استخدم Node.js 22 أو أحدث.
2) ثبّت الاعتمادات بواسطة npm install.
3) نفّذ npm run build لفحص النشر الأساسي، وnpm test لتشغيل اختبارات المزود الوهمي الكاملة (تحتاج مجلد tests).
4) شغّل npm start.
5) لا تغيّر Root Directory: يجب أن يكون المجلد الذي يحتوي server.js وpackage.json وrailway.json.

النشر على Netlify
- تحتفظ الحزمة بإعداد netlify.toml وملف netlify/functions/api.js وسكربت scripts/prepare-netlify.js.
- اربط المستودع أو استخدم Netlify CLI حتى تُبنى الدالة. رفع ملفات HTML وحدها لا يشغّل API.
- اضبط متغيرات البيئة السرية FIREBASE_DATABASE_URL وFIREBASE_SERVICE_ACCOUNT_JSON وSESSION_SECRET. لا تضع مفتاح حساب الخدمة في ملفات الواجهة.

Firebase والأمان
- إعدادات Firebase وقواعد البيانات محفوظة في config.json وdatabase.rules.json.
- admin-auth.json يحتوي بيانات تحقق الإدارة؛ لا تنشر المشروع في مستودع عام ولا تشارك الملف مع أي شخص.
- لا تضف ملفات Service Account أو مفاتيح API أو ملفات .env إلى ZIP.
- اضبط مساحة تخزين دائمة في الاستضافة إذا كنت تعتمد على الملفات المحلية والصور والبيانات التي لا تحفظ في Firebase.
- أنشئ نسخة احتياطية قبل أي ترقية. نجاح الاختبار المحلي لا يثبت وحده اتصال Firebase أو مزود الخدمات الحي بعد النشر.

التحديث المستقبلي
- سكربت scripts/bump-release.js يرفع رقم الإصدار ويحدّث علامات النسخة. بعد استخدامه نفّذ npm test وnpm run build وراجع تغييرات الملفات قبل النشر.

ملاحظة
هذه نسخة نشر خفيفة وليست حزمة تطوير كاملة؛ اختبارات المطور المنفصلة وسجلات الإصدارات القديمة أزيلت لتقليل عدد الملفات. احتفظ بنسخة التطوير الكاملة إذا احتجت إعادة تشغيل مجموعة الاختبارات الشاملة.

الإصدار 5.3: تجميع الخدمات في منصة «الكل» حسب المنصة مع تحميل المزيد لكل مجموعة؛ بطاقات طلباتي المختصرة؛ مزامنة الإدارة عبر مسار الخادم المؤكد؛ وتوحيد واجهة الإدارة والخدمات على الفحمي والبرتقالي. اختُبرت حالات الاسترداد حسابياً، وفُحصت صياغة سكربتات الواجهة قبل النشر. لا يعني هذا اختبار اتصال حي بالمزود أو Firebase بعد النشر.

الإصدار 5.4: تجميع الفئات داخل قائمة الفئة حسب المنصة، إصلاح دورة فتح/إغلاق قوائم الفئة والخدمة على الهاتف، توحيد ألوان طلب جديد ومتجر صدى العراق على الفحمي والذهبي/البرتقالي، وتحسين بطاقات المتجر عند فتح قسم. تم تشغيل اختبارات البناء وفحوصات الحزمة؛ يلزم اختبار حي على Railway للتحقق من عرض Safari والاتصال الفعلي.

تحديث 5.4: إصلاح تجميع فئات المنصات والبحث وإغلاق القوائم وتوحيد ألوان المتجر والإدارة.


إصدار 5.5 — إصلاحات تجربة الطلب والخدمات والإدارة
- توحيد أيقونات المنصات في قوائم الفئات والخدمات.
- توحيد ألوان إنشاء الطلب وإحصائيات الحساب، مع بطاقات طلبات أقصر وخط أوضح.
- إعادة ترتيب أقسام لوحة الإدارة وإرجاع مدير المتجر إلى نمطه السابق.
- تحديث حالة الطلب من المزود عبر مسار آمن، ومنع الاسترداد من جهة المتصفح؛ لا يتم اعتماد الاسترداد إلا بعد تحقق المزود وحفظ قاعدة البيانات.


الإصدار 5.5 (مراجعة الإصلاحات): توحيد أيقونات المنصات داخل الفئات والخدمات، ترتيب الفئات تحت منصاتها في «الكل»، إعادة تصميم بطاقات طلباتي مع سعر/كمية/متبقي/رابط وأزرار نسخ، وتثبيت تحديث/إلغاء الطلب عبر الخادم فقط. تم الإبقاء على تصميم مدير المتجر الأساسي وعدم فرض البرتقالي على كامل لوحة الإدارة. الفحوصات المحلية لا تثبت الاتصال الحي بمزود الخدمات أو Firebase بعد النشر.
